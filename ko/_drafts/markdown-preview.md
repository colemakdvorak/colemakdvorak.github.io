**이 페이지는 로컬에서만 보이는 서식 예시입니다.** `./bin/dev --unpublished`로 실행할 때 표시되며, 실제 배포에는 포함되지 않습니다. 이 파일을 수정하며 마크다운을 시험해 보거나, 본인의 글을 쓸 준비가 되면 삭제해도 됩니다.

## 편안하게 읽을 수 있는 글

이 문단은 긴 글에서 본문의 폭과 줄 간격이 어떻게 보이는지 확인하기 위한 예시입니다. 마크다운으로 내용을 작성하면 테마가 글의 모양을 정리해 줍니다. 문장 안에 **굵은 글씨**, *강조*, [링크](https://www.markdownguide.org/basic-syntax/)를 넣을 수도 있습니다.

### 목록으로 정리하기

- 짧은 관찰이나 생각.
- 조금 더 자세히 덧붙이고 싶은 내용.
- 관련 자료나 다음에 살펴볼 것.

> 인용문은 다른 글의 일부를 소개하거나, 본문과 구분해 보여 주고 싶은 내용을 담을 때 사용할 수 있습니다.

## 코드가 필요할 때

코드 블록의 시작 부분에 언어 이름을 적으면 문법에 맞게 색상이 표시됩니다. 문장 안에서는 `example()`처럼 짧은 코드를 넣을 수 있습니다.

```python
def greet(name: str) -> str:
    return f"안녕하세요, {name}님."

print(greet("독자"))
```

## 표와 각주

| 요소 | 마크다운 작성법 |
| --- | --- |
| 제목 | `## 제목` |
| 강조 | `*강조*` |
| 링크 | `[이름](https://example.com)` |

본문의 흐름을 끊지 않고 참고 내용을 남기고 싶다면 각주를 사용할 수 있습니다.[^example]

[^example]: 각주가 어떻게 표시되는지 확인하기 위한 예시입니다.

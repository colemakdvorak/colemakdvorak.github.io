# World map data

`countries-50m.json` is the unmodified TopoJSON distribution from
`world-atlas@2.0.2`, based on Natural Earth 4.1.0 at 1:50m scale.

- Source: https://github.com/topojson/world-atlas/tree/v2.0.2
- Redistribution license: ISC; see `LICENSE`.
- Natural Earth data: https://www.naturalearthdata.com/about/terms-of-use/

The map uses this local vector backdrop, so it needs no tile service or API key.
Representative country anchors are in `_data/map_places.yml`; the full numbered
journey and detailed city coordinates are in `_data/places.yml`.
